# CANFAR archive-health release v1

This directory is the dissertation's immutable copy of the all-23-channel
archive-health release generated by PilotProxy commit
`2cf4d8cdc94a2beb2299f2b7ece0dcfe2662c6ee`.  The producer worktree was clean,
the focused attached-archive suite passed 21 tests, and the complete repository
suite passed 1,078 tests with four skips.

## Inputs and scope

The release consumes the three files supplied with the dissertation review:

- `_per_pilot.zip`, 728,281,286 bytes, SHA-256
  `c78f4fa8a3b9c11bd22344360ea224c3f88ee8e39276fd61ed15f4e989210aaa`;
- `chime-pilots.zip`, 2,251,998 bytes, SHA-256
  `bc975ac7c97a70f2871eaec166136f5944c98ade1b658cdfdc6a7fa1ee5c697f`;
- `libfstatistic-2.1.0-c85f50dd.so`, SHA-256
  `c85f50ddf898517bc0101d1882c854c3df70b09f0ab0b58803dc32f59e3c6d12`.

The inventory, 23 products, and quarantine ledger reconcile exactly.  The
versioned gate retains 750,279 of 750,461 stored frames and emits one immutable
ledger row for each of 182 exclusions: four detector-invalid all-zero rows and
178 constant native-excess-8 `0x00` rows at the decoded complex-int4 power
ceiling.  The latter are detector-input `0x88` after the lossless ingest repack.
Their aggregate-spectrum contribution is exactly reconstructible and has been
removed from both stored accumulators.  Acquisition-side root cause remains
unknown because the attachments contain neither raw HDF5 nor run logs; that
unknown does not turn a constant negative-full-scale word into a sky
measurement.

## Directory map

- `archive_health_summary.json` is the authoritative machine-readable release:
  product and inventory reconciliation, provenance, input hashes, health counts,
  source cohorts, exposure profiles, fine-anchor measurements/refusals, spectrum
  checks, and stated limitations.
- `archive_exclusion_ledger.jsonl` gives every excluded frame's immutable
  physical key and one or more reason codes.
- `health_corrected_integrated_spectra.npz` contains the repaired relative
  before/after spectrum accumulators and their denominators.
- `diagnostic_manifest.json` authenticates all 92 diagnostic assets.
- `figures/` contains, for every physical channel, a histogram PDF, relative
  time-averaged-spectrum PDF, 300-dpi monthly fine-statistic heatmap, and
  one-page composite diagnostic atlas.  The heatmap is not a raw-voltage
  spectrogram; per-frame voltage spectra were not retained.
- `dissertation_exports/` contains the health-filtered BAO-chain, masking-time,
  census-spectrum, and worked-example tables.
- `dissertation_figures_v4/` contains the provenance-clean figures regenerated
  from those exports.  The two census figures change the channel-28 and
  channel-14 rows affected by the exact ceiling-frame spectrum repair; the
  masking-time figure is numerically unchanged but now has closed provenance.
- `dissertation_report/` and `dissertation_policy/` contain regenerated report,
  threshold-sweep, and policy inputs.
- `dissertation_status_v4/` is a provisional status integration.  It corrects
  superseded superlatives and closes channel 27's off-epoch chain, while
  explicitly preserving legacy epoch operating-point numbers as provisional
  rather than pretending they were re-blinded or health-recomputed.

The 23 composite atlases are also vendored under `figs/archive_health_v1/` for
direct inclusion in Appendix C.  Those duplicates are byte-identical to the
manifested source plates here.

## Reproduction interface

From the producing PilotProxy commit, with the products extracted and the
three attachment paths supplied, the core release is generated by the following
interface (shell variables stand for local paths and are not provenance):

```text
SOURCE_DATE_EPOCH=1787278456 PYTHONPATH=src \
python -m pilot_proxy.archive_health \
  --products-dir "$PRODUCTS_DIR" \
  --output-dir "$OUTPUT_DIR" \
  --fine-chunk-rows 4096 \
  --dissertation-style \
  --product-archive "$PRODUCT_ARCHIVE" \
  --inventory-archive "$INVENTORY_ARCHIVE" \
  --kernel-library "$KERNEL_LIBRARY" \
  --source-repository "$PILOT_PROXY_REPOSITORY" \
  --source-commit 94b1de0e07bdbabb7e544aff22b62ef866e9cf0c \
  --expect-products 23 \
  --expect-excluded-frames 182 \
  --expect-invalid-frames 4 \
  --expect-ceiling-frames 178
```

The requested source revision is the clean historical revision that reproduces
the modern 21-product cohort's recorded package-source digest.  The older
two-product digest is retained but does not match a recovered clean revision.
The audit implementation itself is identified independently by the producing
commit and the package/module hashes inside `archive_health_summary.json`.

## Scientific boundary

The release supports health-filtered scalar distributions, threshold sweeps,
relative time-averaged spectral shape, fine-statistic time--frequency
diagnostics, and reproducible UTC/local/season/LMST exposure accounting.  It
cannot reconstruct an absolute physical PSD, an arbitrary per-frame voltage
spectrogram, exact historical Q16 fine decisions (the three uint64 fine powers
were not retained), missing operations/performance telemetry, or the
visibility-domain transfer required for a final cosmological verdict.
